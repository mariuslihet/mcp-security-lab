Evaluation methodology

    __METHOD__

Metric definitions

Exploit rate
Observed effects / evaluated actor attempts. Errors are counted separately.
Task completion
Case-specific operation and answer-marker rubric. Not a semantic assessment of every statement.
Prevented pair
The baseline effect occurred and the matched hardened effect did not.
Check PASS
The assertion for that row passed. Baseline and hardened assertions expect different effects.
Run status
Completed means scheduled evaluation finished; it does not mean every assertion passed.
